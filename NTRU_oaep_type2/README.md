## NTRU-OAEP-Type2

Based on NTRU in submission to the second round of [NIST's Post-Quantum Cryptography
project](https://csrc.nist.gov/Projects/Post-Quantum-Cryptography/Round-2-Submissions).  See [ntru.org](https://ntru.org) for more information.

Run the following to get the benchmark.

```
cd ref-hps2048509
make test/oaep
./test/oaep
```
